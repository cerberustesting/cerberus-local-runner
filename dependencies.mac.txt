# Cerberus Local Runner - macOS dependency manifest.
#
# Format: <key>=<url>
#   build-macos.sh looks up the keys it needs by name and saves the download under its own
#   fixed destination filename (the name the app expects) - so the url side is free to point
#   anywhere reachable with curl: this delivery server, an artifact registry, or a public
#   release page, with whatever filename the source actually uses.
#
# cerberusRobotProxy is only fetched when CERBERUS_ROBOT_PROXY=true (Robot Proxy feature).
# mitmproxy is intentionally not bundled on macOS - see build-macos.sh and RunnerConfig.java.
#
# jre points at a pinned Eclipse Temurin 21 JRE release archive - fetch-dependencies.js extracts
# it into vendor/jre (not a plain file copy like the others) so the packaged app never needs a
# system-installed JDK/JAVA_HOME.
